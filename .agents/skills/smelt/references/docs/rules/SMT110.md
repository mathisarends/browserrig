# SMT110 module-import-fanout

A module imports more project modules than its policy allows.

- **Category:** dependencies
- **Activation:** policy — structure.max_module_imports or a package contract sets a limit, including zero.
- **Severity when active:** hint

## Why

Many independent project dependencies can signal that a module coordinates too many responsibilities. Unlike SMT108, this review counts distinct direct target modules across every project root package, without requiring a contract on each target package. Repeated imports and multiple symbols from one module count once. Facade re-exports count at the facade path used by the caller, not at their defining modules. Standard-library and third-party imports never count; TYPE_CHECKING imports follow the existing architecture.imports.type_checking policy. Initializers and declared composition roots are exempt by default. This is a design hint, not proof of excessive coupling; reducing imports alone does not simplify a design.

## Bad

```python
# app/client.py
from app.users.read import Read
from app.users.write import Write
from app.billing.pay import Pay
```

## Good

```python
# app/client.py, after deliberate facade review
from app.users import Read, Write
from app.billing import Pay
```

## How to fix

Split a cohesive responsibility into its own module or depend on deliberate package facades. Review import cycles and initializer side effects before adding re-exports. No automatic rewrite is performed. Configure structure.max_module_imports or a package contract's max_module_imports to activate this opt-in hint (zero is supported). A rule setting or --select alone has no effect without a threshold. Closest package limits override the global limit. structure.module_import_exempt defaults to [facades, composition_root]; package overrides, including [], are supported.

## Config

- `structure.max_module_imports`
- `structure.module_import_exempt`
- `structure.contracts`
- `rules`
- `architecture.composition_root`
- `architecture.imports.type_checking`
