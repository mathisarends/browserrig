# SMT106 architecture/composition-root-leak

A module imports the composition root or a declared wiring module.

- **Category:** architecture
- **Activation:** policy — architecture.composition_root or architecture.wiring declares assembly boundaries.
- **Severity when active:** error

## Why

Wiring belongs in one place. When features reach for the container or the bootstrap module, construction logic spreads and dependencies become hidden. With architecture.import_graph.transitive, paths through arbitrary project modules are checked and reported with a shortest import chain.

## Bad

```python
# voice/application/session.py
from gateway.main import container
```

## Good

```python
# voice/application/session.py
class StartSession:
    def __init__(self, sessions: VoiceSessionRepository) -> None: ...
```

## How to fix

Receive dependencies through constructor parameters and register them in the composition root.

## Config

- `architecture.composition_root`
- `architecture.wiring`
- `architecture.import_graph.transitive`
- `architecture.import_graph.type_checking`

Explain it in the terminal with `smelt explain SMT106`.
