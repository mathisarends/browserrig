# Smelt policy decisions

[Back to development](development.md)

Smelt is pinned to `smelt-cli==0.12.0` in the development dependencies and
`uv.lock`. Hooks use `uv run --locked`; CI installs that same lockfile before
running Smelt. The editor schema and bundled skill are generated by this version.

Warnings fail the hooks and CI; hints request contextual review. The existing
rule severities and empty `.smelt/debt.json` are retained. Upgrades do not justify
accepting new debt, raising thresholds to match the current code or excluding
tests wholesale.

## 0.10.0 to 0.12.0

All six new rules from 0.11.0 and 0.12.0 are adopted. The 0.11.1 change to package
API checks is also reviewed: discovered tests now participate in SMT107, SMT108
and SMT319. Report schema 2, configuration version 1 and debt version 2 stay the
same. See the [release notes](https://github.com/mathisarends/smelt/blob/v0.12.0/CHANGELOG.md).

| Rule | Decision | Reason and application |
| --- | --- | --- |
| SMT110 `module-import-fanout` | Hint via `structure.max_module_imports: 8` | Review modules that coordinate more than eight direct project dependencies, including siblings. The budget identifies concentrated integration work alongside the existing layer allowlists; it is not a correctness boundary. Facades and declared composition roots retain the documented exemptions. The adoption scan identifies 15 modules, including `browser.chrome`, `choreography.plugin`, `observation.plugin` and `tools.execution.plugin`. Importing their own facade would introduce initialization cycles, and moving imports alone would conceal rather than reduce their work. Keep these visible for responsibility-level review. |
| SMT363 `complex-comprehension` | Error, default one-loop limit | Refactor all initial findings. Explicit loops separate filtering, mapping and collection assembly; named predicates express world selectors, host matching and preview visibility. `chain.from_iterable` preserves streaming flattening for offscreen controls, alerts and image refs. Geometry still visits corners in the same order, CSV still pads short rows, and record copies remain conditional. No threshold override or suppression is needed. |
| SMT364 `constructor-logic` | Error, default two-decision limit | Refactor all 16 candidates into explicit validation, normalization, serialization and index-building operations. Constructors call those operations before assigning their results; guards still reject invalid inputs before activation. Keep exception types, validation order, separate policy defaults and the composition-root budget decisions. The complete mapping is listed below. |
| SMT365 `cross-module-private-attribute` | Error, default module boundary | This complements the existing private-symbol-import rule by enforcing ownership of statically known private fields and methods. No package-wide relaxation is needed. The adoption scan finds no violations. Unknown receiver types and ambiguous inheritance remain outside the rule's static evidence; a clean scan does not prove all accesses safe. |
| SMT366 `comprehension-in-call-argument` | Error | Name eager collections before passing them to another operation, consistent with the existing await-in-call-argument convention. All six initial findings are repaired: normalized connection headers, frame clients, element-ref lookup, canvas element indices, upload paths and unique todo IDs. Preserve secret wrapping, collection types, validation order and the upload resolve/stage/event sequence. Generators remain lazy; the rule is the released 0.12.0 version, without unreleased aggregate-call detection. |
| SMT367 `excess-private-definitions` | Error, default limit twelve | Split `observation.render` and `files.spreadsheets` into packages with explicit internal responsibilities. Rendering separates snapshot assembly, headers, sections, elements and text formatting. Spreadsheet readers separate XLSX, XLS, ODS and delimited input from shared cell-range selection and table formatting. Each `__init__.py` only re-exports the existing entry points: `render`, or the four `read_*` functions. Explicit `public: ['.']` contracts prevent callers outside either package from importing implementation modules. No limit override, exception or debt is needed. |

The constructor refactor covers every SMT364 candidate:

| Constructors | Extracted responsibility and preserved behavior |
| --- | --- |
| `ActivityKey` | Validate the correlation ID against the normalized activity kind, preserving type and missing-ID errors. |
| `Secret` | Normalize a nonempty domain list and validate the value source before parsing origins; callable secrets are still not evaluated during construction. |
| `TrimInBatches` | Resolve and validate the minimum retention bound before freezing either bound, preserving rejection of bools and invalid windows. |
| `Totp` | Validate digits, period and digest before decoding a literal seed; callable seeds still resolve at use time. |
| `HumanHandoff` | Validate callback, timeout, pause tracking and history as one configuration boundary before storing the options. |
| `TaskMemory` | Normalize the workspace Markdown path, then validate its compaction budget, preserving rejection order. |
| `VideoRecording` | Validate dimensions, frame rate and padding as encoding configuration before initializing recording state. |
| `Secrets` | Validate credential names and value sources, then snapshot the caller's mapping without activating providers. |
| `Readiness` | Share the explicit-None policy fallback while constructing independent initial/ongoing defaults. Caller-supplied falsy policies remain intact. |
| `Document` | Decode optional string-table indices through one accessor; keep tag and layout indexes initialized before queries. |
| `TextCollector` | Build inherited link ownership and ordered control/heading/line-break boundaries in separate index builders. |
| `Occlusion` | Build and sort the painted-box index as one operation before any coverage query. Preserve visibility guards and paint order. |
| `OverlayView` | Serialize options and four enum dictionaries as one presentation payload; keep wire keys and values unchanged. |
| `Agent` | Resolve the model name independently of composing the model profile, context budget and browser pack. |
| `HumanMotor` | Validate typing interval and scroll speed together before storing the pacing configuration. |
| `WheelStep` | Validate finite deltas, then a finite nonnegative dispatch delay, before a wheel step can be used. |

Behavioral regression tests cover combined world invalidation selectors, falsy
initial and ongoing readiness policies, and TOTP settings rejected before seed
decoding. Existing validation, geometry, CSV, retention, capture, redaction and
receipt tests continue to exercise the extracted operations through public behavior.

### Test imports after 0.11.1

Ordinary class/function imports use the existing public facades, including root
re-exports. Tests constructing extraction results use the exported `PageContent`
under the local name `Extraction`, which is the same class. No production export
is added just to satisfy a test. Three kinds of exceptions stay on their specific
import statements, each with its concrete purpose:

- Unit seams test internal algorithms or value bookkeeping independently of
  plugin activation: process cleanup, world and network state, index workers,
  redaction, fingerprints, deltas, scene/receipt projection, recording spans and
  compaction. Publishing those implementation types would enlarge the supported
  API without a production consumer. Module imports used for monkeypatching stay
  at the owning lookup site so the tests still replace the real dependency.
- SMT107 in 0.12.0 mistakes `from browserrig.observation import capture, render`
  for imports of the same-named modules. Both names are explicitly exported
  functions. Keep the facade calls and explain the false positive at the import;
  replacing them with implementation imports or changing the API would defeat
  the contract being tested.
- SMT319 asks the facade identity test to import `BrowserPerception` and its
  `PerceptionExport` alias from the root. That would compare one import with
  itself and stop checking the observation facade. Retain the two import paths.

SMT107 and SMT319 remain errors everywhere else. SMT108 can still suggest
bundling internal imports in focused tests; those hints do not justify exporting
implementation details. No rule is disabled or lowered, no test directory is
excluded and no new debt is recorded for this migration.

## Earlier adoption: 0.8.0 to 0.10.0

The previous upgrade reviewed all fifteen rules added in 0.9.0 and 0.10.0.

| Rule | Decision | Reason and application |
| --- | --- | --- |
| SMT348 `missing-interface-docstring` | Warning | Protocol methods state implementer contracts, including units, missing targets and unavailable data. Class-level descriptions alone leave individual operations ambiguous. |
| SMT349 `stateful-dataclass` | Off | `_Parser`, `_Strip`, `_Runner` and `MemorySummarizer` deliberately accumulate parsing, presentation or execution state. Replacing their dataclasses with hand-written initializers would not improve ownership. |
| SMT350 `missing-broad-except-reason` | Warning | Broad handlers explain the boundary they protect: navigation fails closed, arbitrary host callbacks finish a failed handoff, and failed actions produce receipts. |
| SMT351 `missing-dataclass-option` | Package policy | Require `frozen` and `slots` for recording's result/segment/span value records. Other packages mix values and mutable activation state; a project-wide requirement would conflate their lifetimes. `kw_only` would change existing constructor calls and is not imposed. |
| SMT352 `duplicate-function` | Warning | Native and DOM typing share slip feedback, including the security-sensitive rule that secret-adjacent text is never echoed. Keep their input workflows separate. |
| SMT353 `prefer-project-base-class` | Package policy | Use `browserrig.core.Options` instead of direct Pydantic `BaseModel` inheritance. `_Manifest` has one local, reasoned exception: extraction progress must remain mutable, while `Options` is frozen. |
| SMT354 `prefer-domain-exception` | No global policy | Browser failures already use `BrowserError`. Geometry, reader arguments and retention configuration intentionally raise standard `ValueError`/`TypeError` for invalid caller input. Converting them would change callers' exception handling. |
| SMT355 `duplicate-class-name` | Warning | The Markdown extraction result is named `ExtractedContent`, matching its existing facade export. `PageContent` remains the capture backend's page model; both facade names stay available. |
| SMT356 `duplicate-narrowing-assert` | Off | Current findings guard optional resources established during activation or a particular execution phase. Repeated local assertions make those lifecycle preconditions visible; requiring constructor injection or throwing properties would change the lifecycle or merely relocate the checks. |
| SMT357 `missing-duration-unit` | Warning | Browserrig's numeric durations name their units: `timeout_seconds`, `duration_seconds`, `poll_interval_seconds`, `typing_interval_seconds` and `original_duration_seconds`. Configuration, event payloads, tool schemas, overlay consumers and callers migrate together. Existing `_ms` fields and upstream CDP/HTTP/asyncio/animation parameter names keep their contracts and conversions. |
| SMT358 `prefer-named-duration` | Warning | Name Chrome startup/shutdown budgets, frame setup, DOM seeding, diagnostics and reveal delays by purpose and seconds. Values and evaluation points are preserved; unrelated operations keep separate budgets even when their values match. |
| SMT359 `nested-conditional-expression` | Warning | Explicit branches make model selection, screenshot regions, file classification, cell rendering, fingerprints and element states easier to inspect while preserving branch order and lazy evaluation. |
| SMT360 `mutable-field-in-frozen-dataclass` | Warning | Frozen dataclasses should not accidentally expose mutable collections. Only `CdpEndpoint.headers` has a reasoned field-level exception for its transport-compatible, mutable `dict`; built-in producers create fresh dictionaries. The rest of the project remains checked. |
| SMT361 `parallel-record-fields` | Hint | Review correlated fields before choosing row records or deliberate column storage. CDP's upstream snapshot representation should not be redesigned locally. The adoption scan found no candidates. |
| SMT362 `loop-invariant-collection` | Hint | Review safe lookup reuse without changing guards, empty-loop behavior or evaluation order. Its initial immutable dataclass/tuple inference does not cover many Pydantic/CDP objects here. The adoption scan found no candidates. |

The omitted rules can be revisited when their underlying API or lifecycle policy
changes. Do not add debt or weaken existing checks merely to make an upgrade pass.
