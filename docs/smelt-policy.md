# Smelt policy decisions

[Back to development](development.md)

Smelt is pinned to `smelt-cli==0.10.0` in the development dependencies and
`uv.lock`. Hooks use `uv run --locked`; CI installs that same lockfile before
running Smelt. The editor schema and bundled skill are generated by this version.

The upgrade from 0.8.0 reviews all fifteen rules added in 0.9.0 and 0.10.0.
Warnings fail the hooks and CI; hints request contextual review. Existing rule
severities and `.smelt/debt.json` are retained.

| Rule | Decision | Reason and application |
| --- | --- | --- |
| SMT348 `missing-interface-docstring` | Warning | Protocol methods state implementer contracts, including units, missing targets and unavailable data. Class-level descriptions alone leave individual operations ambiguous. |
| SMT349 `stateful-dataclass` | Off | `_Parser`, `_Strip`, `_Runner` and `MemorySummarizer` deliberately accumulate parsing, presentation or execution state. Replacing their dataclasses with hand-written initializers would not improve ownership. |
| SMT350 `missing-broad-except-reason` | Warning | Broad handlers explain the boundary they protect: navigation fails closed, arbitrary host callbacks finish a failed handoff, and failed actions produce receipts. |
| SMT351 `missing-dataclass-option` | Package policy | Require `frozen` and `slots` for recording's result/segment/span value records. Other packages mix values and mutable activation state; a project-wide requirement would conflate their lifetimes. `kw_only` would change existing constructor calls and is not imposed. |
| SMT352 `duplicate-function` | Warning | Native and DOM typing share slip feedback, including the security-sensitive rule that secret-adjacent text is never echoed. Keep their input workflows separate. |
| SMT353 `prefer-project-base-class` | Package policy | Use `browserrig.core.Options` instead of direct Pydantic `BaseModel` inheritance. `_Manifest` has one local, reasoned exception: extraction progress must remain mutable, while `Options` is frozen. |
| SMT354 `prefer-domain-exception` | No global policy | Browser failures already use `BrowserError`. Geometry, reader arguments and retention configuration intentionally raise standard `ValueError`/`TypeError` for invalid caller input. Converting them would change callers' exception handling. |
| SMT355 `duplicate-class-name` | Warning | The Markdown extraction result is named `ExtractedContent`, matching its existing facade export. `PageContent` remains the capture backend's page model; both facade names stay available. |
| SMT356 `duplicate-narrowing-assert` | Off | Current findings guard optional resources established during activation or a particular execution phase. Repeated local assertions make those lifecycle preconditions visible; requiring constructor injection or throwing properties would change the lifecycle or merely relocate the checks. |
| SMT357 `missing-duration-unit` | Warning | Browserrig's numeric durations name their units: `timeout_seconds`, `duration_seconds`, `poll_interval_seconds`, `typing_interval_seconds` and `original_duration_seconds`. Configuration, event payloads, tool schemas, overlay consumers and callers migrate together. Existing `_ms` fields and upstream CDP/HTTP/asyncio/animation parameter names keep their contracts and conversions. |
| SMT358 `prefer-named-duration` | Warning | Name Chrome startup/shutdown budgets, frame setup, DOM seeding, diagnostics and reveal delays by purpose and seconds. Values and evaluation points are preserved; unrelated operations keep separate budgets even when their values match. |
| SMT359 `nested-conditional-expression` | Warning | Explicit branches make model selection, screenshot regions, file classification, cell rendering, fingerprints and element states easier to inspect while preserving branch order and lazy evaluation. |
| SMT360 `mutable-field-in-frozen-dataclass` | Warning | Frozen dataclasses should not accidentally expose mutable collections. Only `CdpEndpoint.headers` has a reasoned field-level exception for its transport-compatible, mutable `dict`; built-in producers create fresh dictionaries. The rest of the project remains checked. |
| SMT361 `parallel-record-fields` | Hint | Review correlated fields before choosing row records or deliberate column storage. CDP's upstream snapshot representation should not be redesigned locally. The adoption scan found no candidates. |
| SMT362 `loop-invariant-collection` | Hint | Review safe lookup reuse without changing guards, empty-loop behavior or evaluation order. Its initial immutable dataclass/tuple inference does not cover many Pydantic/CDP objects here. The adoption scan found no candidates. |

The omitted rules can be revisited when their underlying API or lifecycle policy
changes. Do not add debt or weaken existing checks merely to make an upgrade pass.
