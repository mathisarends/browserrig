# Migration guides

[Documentation index](index.md) · [Changelog](../CHANGELOG.md)

Start with the guide for the next minor version after the one you use. Apply the
guides in version order if you are upgrading across several releases.

| Target version | Main changes |
| --- | --- |
| [0.6](migration-0.6.md) | API changes from 0.5.x, observation modes and host event envelopes |
| [0.7](migration-0.7.md) | API changes from 0.6.x |
| [0.8](migration-0.8.md) | Browser defaults and pointer tools |
| [0.9](migration-0.9.md) | Harnessed 0.20, browser errors, screenshot freshness and wait tools |
| [0.10](migration-0.10.md) | Composable perception, Harnessed 0.22, approval defaults and session stores |
